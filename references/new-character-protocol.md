# New character protocol

## 1. Justify the character

Give the character one recurring teaching function that the current cast cannot express cleanly. Examples: skeptical tester, data librarian, safety guard, tool operator, user proxy, or domain expert.

## 2. Preserve the project style, not another character

Follow the project’s medium, line, palette logic, and facial system. Create a distinct silhouette with at least three identifiers beyond color: proportions, head shape, accessory, movement, antenna or ears, signature prop, or clothing shape.

## 3. Register before use

Complete the entry from `character-bible-template.md`. State what must always remain and what must never be added.

## 4. Make a reference sheet

Generate front, three-quarter, side, expressions, action pose, and scale comparison. Use the project style references, not another franchise or named character. Approve the sheet before inserting the character into episode pages.

## 5. Add without drift

Reference the approved sheet and repeat the invariant block every time the character appears. Do not redesign existing cast members to make the new character fit.
